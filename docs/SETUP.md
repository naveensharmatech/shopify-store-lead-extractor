# Setup & Deployment

## Local Development

```bash
git clone https://github.com/naveensharmatech/shopify-store-lead-extractor.git
cd shopify-store-lead-extractor
pip install -r requirements.txt
python -m src.main
```

## Apify Deployment

1. Push to GitHub
2. Connect to Apify
3. Configure input schema
4. Deploy actor
