# Use Cases (illustrative)

- **Ecommerce agencies:** prospect stores in a niche, filter by missing apps (e.g. no Klaviyo) to pitch email marketing.
- **Shopify consultants:** shortlist stores by `catalogSize` for catalog/CRO audits.
- **App vendors:** find stores using a competitor app (e.g. Yotpo vs Judge.me).
- **Market research:** sample app adoption by niche.

Input: [input-config.json](input-config.json). Output: [output-samples.json](output-samples.json). Sample data is fictional.
